FREESTYLE DREWP - GUIA DE INSTRUÇÕES (só para ti, não é preciso enviar para o GitHub)
===========================================================================

O QUE VEM NESTE ZIP (5 ficheiros, todos na mesma pasta)
  index.html      página Início
  catalogo.html   página Catálogo
  contacto.html   página Contacto
  style.css       todo o visual (cores, espaços, telemóvel/computador)
  script.js       todo o funcionamento (catálogo, cores, sacola, WhatsApp)
Dentro de cada ficheiro há um GUIA no início, em comentários, a explicar o que
faz cada parte. Os comentários só se vêem no código; os clientes não os vêem.

COMO PUBLICAR NO GITHUB
  1. Extrai o ZIP no telemóvel/computador.
  2. No repositório FREESTYLEDREWP: Add file > Upload files.
  3. Envia os 5 ficheiros (substituem os antigos). NÃO apagues a pasta "imagens".
  4. Em baixo, toca em "Commit changes" e espera 1 a 2 minutos.
  5. Abre o site num separador privado (para não mostrar a versão antiga).

COMO FUNCIONA O CATÁLOGO (o que pediste)
  - Peça COM fotografias: aparece. Peça SEM fotografias: fica completamente oculta
    (sem cartão cinzento, sem nome, sem preço, sem botão e sem buracos).
  - A ordem é sempre a do catálogo. Se só a Polo 01 tiver fotos, ela fica em 1.º lugar.
    Quando adicionares a Camisa 01, ela entra antes da Polo 01 sozinha.
  - Vale para todas as categorias: Camisas, Calças, Chapéus, Sacolas e Camisolas.
  - Categoria sem nenhuma peça com fotos: o filtro, o cartão do Início e a ligação
    do rodapé ficam escondidos até haver fotos.
  - Não precisas de mexer no HTML nem no JS para mostrar uma peça: só enviar as fotos.
  - No catálogo as fotos trocam de cor sozinhas. Em "Encontra o teu estilo" (Início)
    as fotos são FIXAS: mostram a primeira peça disponível de cada categoria.

PARA O SITE SER RÁPIDO
  - Comprime as fotos: cerca de 800 x 1000 px e menos de 200 KB cada.
    Fotos pesadas (vários MB) são a maior causa de lentidão.
  - Os fundos do Início: cerca de 1600 x 900 px e menos de 400 KB.
  - Na 1.ª visita o site descobre que fotos existem (cerca de meio segundo).
    Da 2.ª visita em diante guarda isso no telemóvel e mostra tudo no mesmo instante.

SE UMA PEÇA NÃO APARECER
  1. O nome tem de ser exacto: minúsculas, sem espaços, ex.: polo2-branco.jpg
  2. A foto tem de estar dentro da pasta imagens/ (na raiz do repositório).
  3. A extensão tem de ser a verdadeira (não renomeies PNG para JPG à mão).
  4. Depois do commit espera 1 a 2 minutos e abre num separador privado.

PREÇOS (já definidos)
  Camisa    800 MT      Polo     1000 MT
  Calça    1200 MT      Chapéu    450 MT
  Sacola    450 MT      Camisola 1200 MT
  Aparecem nos cartões, na janela de detalhes, na sacola (com o total) e na
  mensagem do WhatsApp. "Menor preço" e "Maior preço" já funcionam.
  Para mudar: script.js > PRICE_BY_TYPE (preço de cada tipo de peça).
  Para mudar UMA peça só: script.js > PRICES, ex.:  camisa3: 900

COMENTÁRIOS NO CÓDIGO
  Cada ficheiro tem, no início, um GUIA a dizer o que faz e onde editar.
  No script.js todas as funções têm uma linha a explicar para que servem.
  No style.css há um índice e cada bloco importante diz para que serve.
  Nos HTML, cada secção tem um comentário a explicar o que é.
  Os comentários só se vêem no código; os clientes nunca os vêem.

ONDE EDITAR (início do script.js, secção 1 - CONFIGURAÇÃO)
  CONFIG.whatsapp  número de WhatsApp (já está 258861697479)
  CONFIG.phone, CONFIG.instagram, CONFIG.facebook, CONFIG.location
  PRICES           preços, ex.: camisa1: 1500
  AVAILABILITY     ex.: chapeu2: "Esgotado"
  PRODUCT_NAMES    mudar o nome de uma peça
  PRODUCT_COLORS   limitar as cores de uma peça
